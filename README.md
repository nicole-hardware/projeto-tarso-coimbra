# 📘 Cruzadinha Educacional

## Visão Geral do Projeto

O **Cruzadinha Educacional** é um projeto criado para apoiar o aprendizado da língua portuguesa escrita de uma forma mais leve e interativa. A proposta principal é oferecer um jogo de **palavras cruzadas** totalmente acessível e fácil de usar.

O projeto foi pensado especialmente para os alunos do **Centro Municipal Dr. Tarso de Coimbra**, que possuem **deficiência auditiva e surdez**. A ferramenta busca tornar o processo de aprendizagem mais inclusivo, oferecendo atividades visuais, simples e úteis no dia a dia escolar.

---

## Objetivo

O objetivo central é disponibilizar uma página web com jogos que auxiliem o desenvolvimento do vocabulário e o reconhecimento das palavras em português escrito.  
A ideia é permitir que o aluno aprenda enquanto brinca, de maneira leve e motivadora.

---

## Problema Identificado

Alunos com deficiência auditiva enfrentam desafios específicos no aprendizado da língua portuguesa escrita. Entre os principais fatores estão:

- Conteúdos pouco adaptados às suas necessidades.  
- Métodos tradicionais que não acompanham suas formas de aprendizagem.  
- Falta de jogos e recursos digitais voltados a esse público.  

Com isso, muitas vezes o estudo se torna mais cansativo, desmotivador e pouco acessível.

---

## Motivação

O projeto nasceu do desejo de:

- Tornar o aprendizado mais prazeroso e eficiente.  
- Criar materiais simples, funcionais e acessíveis para todos.  
- Apoiar professores e intérpretes com recursos complementares.  
- Fornecer uma experiência real de desenvolvimento aos criadores, unindo educação, inclusão e tecnologia em algo concreto.

---

## Tecnologias Utilizadas

Para manter a proposta simples e acessível, o projeto utiliza:

- **HTML5** – estrutura do site  
- **CSS3** – visual e organização da página  
- **JavaScript** (opcional) – interações do jogo  
- **Arquivos de imagem e ícones**  

Não é necessário instalar nada adicional para rodar o projeto.

---

## Requisitos Mínimos

O projeto foi criado para funcionar de forma simples. Você só precisa de:

- Um navegador atualizado (Chrome, Firefox, Edge, etc.)  
- O arquivo `.zip` do projeto baixado e extraído  

Não é necessário instalar programas adicionais ou usar servidor.

---

## Como Instalar

1. Baixe o arquivo `.zip` contendo o projeto.  
2. Clique com o botão direito no arquivo compactado e selecione:  
   - **“Extrair aqui”** ou  
   - **“Extrair para…”**  
3. Aguarde a descompactação.  
4. Abra a pasta que foi criada.

---

## Como Usar

### **Executar o jogo da cruzadinha**

1. **Abra a pasta do projeto.**  
   Dentro dela, procure o arquivo:

   CRUZADINHA.html

3. **Clique duas vezes no arquivo CRUZADINHA.html.**  
Seu navegador vai abrir automaticamente.

4. **A página será carregada no navegador.**  
Nenhuma instalação ou configuração é necessária.

5. **Comece a jogar.**  
A cruzadinha funciona totalmente offline.  
Basta preencher as palavras e interagir com o jogo normalmente.

---

## Acessibilidade

O projeto foi desenvolvido com atenção especial à acessibilidade, especialmente para alunos com deficiência auditiva. Entre os cuidados estão:

- Interface visual clara e objetiva  
- Navegação simples  
- Conteúdo direto e sem dependência de áudio  
- Compatível com navegação offline
